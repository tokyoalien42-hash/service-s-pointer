# Milk custom SVG icons

原始图标素材来自用户提供的 SVG 压缩包。文件名改为 ASCII，避免 GitHub Pages 子路径及手机浏览器对中文 URL 编码产生差异。

## 当前已启用

- `messages.svg`：顶部会话管理入口
- `people.svg`：顶部群聊入口
- `settings.svg`：顶部设置入口
- `time.svg`：顶部切换主题入口（由 `js/core.js` 动态刷新时保持）
- `album.svg`：聊天图片/相册入口
- `plane.svg`：主动发送设置和主题预览；聊天发送按钮恢复原版图标
- `phone.svg`：视频通话入口及通话记录中的通话标识

## 暂未启用（保留备用）

其余 SVG 暂时保存在本目录，未批量替换到界面，避免图标过多、过度装饰。

消息操作菜单（回复、收藏、删除等）和通话挂断图标仍使用项目原有图标。
